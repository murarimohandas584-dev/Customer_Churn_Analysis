# Telco Customer Churn Dataset

This folder contains the dataset used for the **Customer Churn Analysis** project.

## Dataset File

The project requires the following dataset:

- `WA_Fn-UseC_-Telco-Customer-Churn.csv`

## Dataset Source

The dataset is the **Telco Customer Churn Dataset**, originally provided by **IBM** and widely available through Kaggle for learning and analysis purposes.

The original CSV file is **not included in this GitHub repository** because the dataset is not required to run the repository's documentation and including the raw dataset is unnecessary.

## How to Use

To run the project locally:

1. Download the Telco Customer Churn dataset from its original source.
2. Place the CSV file inside this `data` folder.
3. Make sure the filename is:

```text
WA_Fn-UseC_-Telco-Customer-Churn.csv
