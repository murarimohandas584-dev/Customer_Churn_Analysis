# Customer Churn Analysis & Prediction

## 📌 Overview

Customer churn occurs when customers stop using a company's products or services. 
For telecom companies, understanding why customers leave is important for improving 
customer retention and reducing potential revenue loss.

This project analyzes the **Telco Customer Churn dataset** using Python and applies 
machine learning to predict whether a customer is likely to churn.

The project combines **Data Analysis, Data Visualization, Data Preprocessing, and 
Machine Learning** to understand customer behavior and identify important factors 
associated with churn.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze customer churn patterns
- Clean and preprocess customer data
- Perform exploratory data analysis (EDA)
- Visualize important customer characteristics
- Build a machine learning model for churn prediction
- Evaluate model performance
- Identify important features used by the model
- Generate useful business insights

---

## 📊 Dataset

The project uses the **Telco Customer Churn dataset**.

The dataset contains information about customers, their services, billing details, 
and whether they left the company.

### Important Features

| Feature | Description |
|---|---|
| `gender` | Customer gender |
| `SeniorCitizen` | Whether the customer is a senior citizen |
| `Partner` | Whether the customer has a partner |
| `Dependents` | Whether the customer has dependents |
| `tenure` | Number of months the customer has stayed |
| `PhoneService` | Whether the customer has phone service |
| `MultipleLines` | Multiple phone lines subscription |
| `InternetService` | Type of internet service |
| `OnlineSecurity` | Online security subscription |
| `OnlineBackup` | Online backup subscription |
| `DeviceProtection` | Device protection subscription |
| `TechSupport` | Technical support subscription |
| `StreamingTV` | Streaming TV subscription |
| `StreamingMovies` | Streaming movies subscription |
| `Contract` | Customer contract type |
| `PaperlessBilling` | Paperless billing status |
| `PaymentMethod` | Customer payment method |
| `MonthlyCharges` | Monthly amount charged |
| `TotalCharges` | Total amount charged |
| `Churn` | Whether the customer left the company |

### Target Variable

`Churn` is the target variable:

- **No** → Customer stayed
- **Yes** → Customer churned
